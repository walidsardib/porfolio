# Portfolio — Walid Sardi

Portfolio personal creado con Astro, contenido extraído desde https://walidsardib.es.

Requisitos:
- Node.js 18+ (recomendado)

Instalación y ejecución (PowerShell):

```powershell
cd c:/Users/walid/Desktop/porfolio
npm install
npm run dev
```

Estructura principal:
- `src/pages` — páginas de Astro
- `src/components` — componentes (Layout)
- `src/styles.css` — estilos globales
- `public/assets` — imágenes/avatars

Contenido incluido:
- Nombre, bio y enlaces sociales (GitHub, LinkedIn)
- Sección de proyectos con enlaces a repos y demo
- Lista de skills extraída del sitio
